# Location & Settings UI Module (`location-settings.md`)

## Overview
The Location & Settings UI module (`src/components/location-search.tsx` and `src/components/settings-button.tsx`) manages city selection popovers and app settings drawers.

## Files
- `src/components/location-search.tsx` — Popover dialog with fuzzy search across 24 Gujarat cities + 6 major metros (Ahmedabad, Surat, Vadodara, Rajkot, Bhavnagar, Jamnagar, Mumbai, Delhi, etc.).
- `src/components/settings-button.tsx` — Slide-over sheet controlling:
  - Language toggle (English / ગુજરાતી)
  - Theme mode toggle (Light / Dark / System)
