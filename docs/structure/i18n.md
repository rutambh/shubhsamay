# Internationalization Module (`i18n.md`)

## Overview
The i18n module (`src/lib/i18n.ts` and `src/hooks/use-lang.tsx`) provides bilingual support (English and Gujarati) and timezone formatting helpers.

## Files
- `src/lib/i18n.ts` — Comprehensive string tables for UI elements, event names, method names, panchang terms, and `formatTzTime` / `formatTzDate` helpers.
- `src/hooks/use-lang.tsx` — React `LanguageContext` and `useLang()` custom hook supporting `'en'` and `'gu'` modes with `localStorage` persistence (`shubh_samay_lang`).

## Hydration Strategy
- Context initializes with `'en'` to ensure SSR matching, then reads `localStorage` in a client `useEffect` to avoid Next.js hydration mismatches.
